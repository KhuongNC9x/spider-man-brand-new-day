## 📋 Mission Briefing

Two tickets. One empty seat on my right. Spider-Man handles saving the world — she only needs to save my evening.

This is a digital invitation card, built to be swiped, tapped, and (hopefully) answered with an enthusiastic **YESSS**.

## ✨ Features

- 🕸️ **Web-tear intro** — the whole screen is covered in spider webs; swipe to tear them away and reveal the invitation
- 🎬 **Cinematic entrance** — a spider drops down on a silk thread, the ticket swings in with a 3D flip
- 🎟️ **Real ticket details** — showtime, cinema, seats, and booking code, styled as a proper ticket stub with perforated edges
- ⏳ **Live countdown** — glowing timer counting down to 19:30, switching to *"The movie is on — run!"* when it hits zero
- 🖱️ **3D tilt + holographic glare** — the ticket follows your cursor (desktop only, so scrolling on mobile stays smooth)
- 🕷️ **Interactive spider** — tap it, it thwips
- 💥 **THWIP splats** — tap anywhere on the background to shoot a web
- 🎆 **The YESSS sequence** — screen flash, comic-book rays, THWIP stamps, canvas fireworks with real particle trails, a spider swinging across the screen, and three waves of emoji confetti
- 😆 **The "let me think" button** — gets progressively more desperate with each click, then gives up and disappears. Resistance is futile.

## 🛠️ Tech Stack

- Vanilla **HTML / CSS / JavaScript** — zero frameworks, zero dependencies, zero build step
- **Canvas API** for the web-tear scratch effect and particle fireworks
- **CSS animations** everywhere, with full `prefers-reduced-motion` support
- Fonts: *Anton* + *Be Vietnam Pro*
- Powered by: caffeine and unconditional love ❤️
